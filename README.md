# HandbrakeAutomateSite

This is the promotional/marketing website for the [HandbrakeAutomate](https://github.com/rjester/HandbrakeAutomate) PowerShell project.

## About

HandbrakeAutomate is a collection of PowerShell scripts that automate DVD ripping using MakeMKV and HandBrake. This site serves as the landing page and documentation hub for the project.

## GitHub Pages

This site is published using GitHub Pages. To enable GitHub Pages:

1. Go to the repository Settings
2. Navigate to Pages section
3. Under "Source", select the branch to deploy (typically `main` or `copilot/create-promotional-site`)
4. Select the root folder `/` as the source
5. Save the changes

The site will be available at: `https://rjester.github.io/HandbrakeAutomateSite/`

## Local Development

To view the site locally:

1. Clone this repository
2. Open `index.html` in your web browser

No build process is required - this is a static HTML/CSS site.
