Getting Started

Prerequisites

  • Windows machine with a DVD drive
  • PowerShell 7+ installed
  • MakeMKV installed
  • HandBrakeCLI installed

Installation

# Clone the repository
git clone https://github.com/rjester/HandbrakeAutomate.git
cd HandbrakeAutomate

Quick Start

# Run the DVD ripping script
pwsh ./src/Invoke-DvdRip.ps1 `
    -OutputPath C:\Videos `
    -PresetFile ./src/presets/DvdRip.json `
    -PresetName "DvdRip Balanced" `
    -OutputFormat mp4

Documentation

📘 Core Scripts

  • Invoke-DvdRip.ps1 - Main orchestrator for the ripping and encoding process
  • Invoke-MakeMKV.ps1 - Handles MakeMKV operations (drive detection, title listing, ripping)
  • Invoke-HandBrakeEncode.ps1 - Wraps HandBrakeCLI for encoding with progress tracking
  • Config.ps1 - Configuration management and tool path detection
  • Logger.ps1 - Logging functionality for debugging and auditing

⚙️ Configuration

The scripts support flexible configuration through:

  • JSON configuration files for default settings
  • Command-line parameters to override defaults
  • Persistent tool path storage for convenience
  • Custom HandBrake preset files

🔍 Workflow

  1. Insert DVD and run the script
  2. Auto-detection of tools and DVD drive
  3. Title selection (interactive or automatic)
  4. MakeMKV extracts selected title(s)
  5. HandBrake encodes to desired format
  6. Automatic cleanup of temporary files
  7. Detailed logs for each operation

💡 Advanced Options

  • -KeepTemp - Preserve temporary files for debugging
  • -TitleNumber - Specify exact title to rip
  • -OutputFormat - Choose between MP4 or MKV
  • -Verbose - Enable detailed output
  • Custom preset configuration via JSON files
