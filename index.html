Automate DVD Ripping & Encoding

Key Features

End‑to‑End Automation

Rip, encode, clean up, and log with a single command.

Smart Detection

Automatically locates MakeMKV, HandBrakeCLI, and DVD drives.

Custom Presets

Use HandBrake presets or your own JSON-based configuration.

Interactive or Automatic

Choose titles manually or let the script decide.

Progress & Logging

Real-time feedback and detailed logs for troubleshooting.

Clean by Default

Temporary files are removed unless you choose to keep them.

How It Works

  1. Insert DVD
  2. Detect Tools
  3. Select Title
  4. MakeMKV Rip
  5. HandBrake Encode
  6. Cleanup
  7. Logs Saved

Core Scripts

  • Invoke-DvdRip.ps1 – Orchestrates the entire workflow
  • Invoke-MakeMKV.ps1 – Disc detection and ripping
  • Invoke-HandBrakeEncode.ps1 – Encoding and progress parsing
  • Config.ps1 – Tool paths and configuration
  • Logger.ps1 – Structured logging
  • Presets – JSON-based encoding definitions
